# Optical Manager

برنامج إدارة بسيط لمحل النظارات وفحص النظر.

## المتطلبات
- Node.js 20+ (يفضل إصدار LTS حديث).
- npm.

## التشغيل أثناء التطوير
```bash
npm install
npm run dev
```
ثم افتح العنوان الذي يظهر في Terminal.

> النسخة الحالية Web App للتطوير والاختبار فقط. المستخدم النهائي لن يحتاج إلى Terminal بعد تحويل المشروع إلى Electron.

## قاعدة البيانات
يتم إنشاء SQLite تلقائيًا داخل:
`data/optical-manager.db`

لا تحذف هذا الملف لأنه يحتوي على بيانات البرنامج.

## النسخ الاحتياطي
من الإعدادات يمكن تحميل نسخة JSON، واستعادتها عند الحاجة من نفس الصفحة.

## التحويل إلى Desktop
بعد اكتمال الاختبار الوظيفي سيتم إضافة Electron وتغليف التطبيق كبرنامج Windows مستقل.

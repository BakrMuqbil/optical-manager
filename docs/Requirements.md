# Optical Manager — متطلبات النسخة الأولى

## الهدف
برنامج Web بسيط لمستخدم واحد في محل نظارات وفحص نظر. يحفظ بيانات العملاء، فحوصات النظر والوصفات، والفواتير، مع البحث والطباعة. بعد الاختبار سيُغلف كتطبيق Windows عبر Electron ويعمل محليًا مع SQLite بدون اعتماد على الإنترنت.

## الوحدات
- Dashboard: أعداد العملاء والفحوصات والفواتير وإجمالي المبيعات.
- العملاء: إضافة، تعديل، أرشفة، بحث بالاسم/الهاتف/رقم العميل، وملف العميل.
- فحوصات النظر: OD/OS وSPH/CYL/AXIS/ADD/Prism/Base وPD/Near PD والملاحظات والتاريخ والفاحص.
- الوصفة: عرض وطباعة الفحص.
- الفواتير: عدة بنود، كمية، سعر، خصم، إجمالي، مدفوع، متبقي، حالة، ملاحظات.
- طباعة الفاتورة من المتصفح وإمكانية Save as PDF.
- إعدادات المحل: الاسم والهاتف والعنوان والعملة ومقاس الورق والنص السفلي.
- Backup: تصدير واستعادة JSON.

## خارج MVP
SaaS، تعدد المستخدمين، الفروع، المخزون، الموردون، المحاسبة المتقدمة، WhatsApp/SMS، AI، التكامل مع أجهزة الفحص.

## التقنية
Next.js 16 + React 19 + TypeScript + Tailwind CSS + SQLite عبر better-sqlite3. لا يوجد Prisma في هذه النسخة لتقليل التعقيد وتسهيل التغليف لاحقًا داخل Electron.

## قاعدة البيانات
`customers`, `exams`, `invoices`, `invoice_items`, `settings`.

## مسار التحويل لاحقًا
Web App → اختبار وظيفي كامل → Electron → Windows Installer (`Optical Manager.exe`).

## معيار النجاح
إضافة عميل، العثور عليه لاحقًا، تسجيل فحص، رؤية التاريخ، طباعة الوصفة، إنشاء فاتورة متعددة البنود، حساب المدفوع والمتبقي، إعادة فتح الفاتورة وطباعتها، وإنشاء/استعادة نسخة احتياطية.

# Implementation Update

تم تبسيط التطبيق إلى نموذج تشغيل واحد سريع باسم **فاتورة**.

## ما تم تغييره
- إزالة واجهات العملاء والفحوصات المنفصلة.
- تحويل `/invoices/new` إلى النموذج الموحد.
- إزالة اختيار العميل من القائمة؛ يتم إدخال الاسم والجوال مباشرة.
- ربط العميل تلقائيًا برقم الجوال عند وجوده، وإنشاء سجل داخلي عند الحاجة.
- نقل بيانات قياسات النظر إلى سجل الفاتورة نفسه.
- إزالة Prism وBase من النموذج الموحد.
- إزالة رقم الفحص المستقل وعدم توليد `EXAM-*` جديد.
- استخدام `invoice_number` كرقم وحيد للعملية.
- إضافة حساب السعر والخصم والإجمالي والمدفوع والمتبقي داخل نفس النموذج.
- إضافة زر **حفظ وطباعة** للطباعة السريعة.
- إعادة بناء قالب الطباعة ليجمع القياسات والحساب في فاتورة واحدة.
- جعل العملة وحجم الورق في الطباعة يعتمدان على الإعدادات الحالية.
- تحديث لوحة التحكم لتعرض مؤشرات الفواتير والمبالغ.
- إنشاء كشف حساب مستقل يومي/شهري/سنوي مع البحث والفلترة والتعديل والطباعة والحذف.
- الاحتفاظ بجدول `exams` القديم فقط للتوافق مع البيانات السابقة، مع ترحيل بيانات الفحص المرتبطة بالفاتورة إلى حقول الفاتورة تلقائيًا.
- تحديث النسخ الاحتياطي لاستيعاب البنية الموحدة مع دعم النسخ القديمة.
